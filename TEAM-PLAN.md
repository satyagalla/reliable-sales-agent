# Trust Desk — four-hour team plan

Hypothetical division of work, not a claim of multi-engineer/multi-agent implementation. The actual build uses one application/database without subordinate agents.

| Owner                         | Scope                                                                                  | Checkpoint                             |
| ----------------------------- | -------------------------------------------------------------------------------------- | -------------------------------------- |
| Engineer A: pipeline          | Signed ingestion, tenant resolution, queue/dedupe/supersession, structured call, audit | Minute 45: persisted proposal/decision |
| Engineer B: rules/reliability | Money/VAT/minimums/services, trust, approval/outbox, crash semantics                   | Minute 60: unit/cross-process checks   |
| Engineer C: operator/quality  | Inbox/evidence/RTL, cases/judge/calibration, docs                                      | Minute 75: stored pages without key    |

**0–15m:** agree schemas, scoped keys, money, storage ownership and fixture labels. Confirm runtime, seeds, credentials/deadline.

**15–75m:** complete persistent spine, integrate using an explicit fixture, then genuine provider. Keep external calls outside transactions. Select reliability/Arabic depth.

**75–140m:** finish approvals/outbox/audit and 36 cases/rubric; run baseline/degraded. Review each other's authority boundaries before adding scope.

**140–190m:** test races, supersession, money/policy/trust, retries and uncertainty. Personally label ten real outputs, reporting disagreement. Preserve failed evidence.

**190–220m:** fresh-start/offline/Arabic/export checks, secrets and incremental history; finish required docs.

**220–240m:** personally record 8–12 minute Loom and submit repo/zip including `.git`. State incomplete runs, calibration, visual checks or original lines. Cut integrations/deployment/polish before the spine.
